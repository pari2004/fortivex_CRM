# Fortivex CRM

Custom CRM web application for Fortivex AI to manage client leads, sales pipelines, customer interactions, and business workflows in one centralized dashboard.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org)
- **Database ORM**: [Prisma](https://www.prisma.io/)
- **AI Integrations**: Google Generative AI / Vercel AI SDK
